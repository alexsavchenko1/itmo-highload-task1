# ITMO Highload TASK1 — этапы 1–3

Java 21 + Spring Boot 3.5.16 + Tomcat + Micrometer + Docker Compose +
Prometheus 3.5.0 + Grafana 12.2.0.

Инструкции по запуску и проверке: [README_STAGE3.md](README_STAGE3.md).

Этап 1: Java CRUD-сервис + /health.  
Этап 2: /metrics, /handlers, счётчики и гистограммы.  
Этап 3: два экземпляра приложения, Prometheus и Grafana с автоматическим datasource.  
Далее: генератор дашбордов и генератор нагрузки.
